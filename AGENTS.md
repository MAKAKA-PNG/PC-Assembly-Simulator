
# PC Assembly Simulator

## Описание
Разрабатывается образовательная 3D-игра по сборке персонального компьютера.

Курсовая работа:
«Разработка компьютерной игры на движке Unity».

Среда разработки:
- Unity 6
- C#
- Universal Render Pipeline (URP)
- Visual Studio 2022
- Windows 10/11

## Основные механики
- Свободная орбитальная камера.
- Выбор комплектующих мышью.
- Информационные карточки компонентов.
- Установка деталей в соответствующие слоты.
- Проверка аппаратной совместимости.
- Подключение кабелей выбором двух портов.
- Проверка полноты сборки.
- Обучение с подсказками.
- Самостоятельная практика.
- Диагностика и оценивание.

## Контекст разработки
Перед началом работы прочитай Docs/PROJECT_CONTEXT.md.

Сопоставляй документацию с реальным состоянием файлов проекта.

## Правила разработки
1. Сначала изучай существующую реализацию.
2. Не переписывай работающие системы без необходимости.
3. Соблюдай соглашения Microsoft C#.
4. Сохраняй совместимость существующих MonoBehaviour.
5. Не переименовывай публичные поля без необходимости.
6. Не удаляй сцены, префабы и ScriptableObject.
7. Не изменяй Unity-проект без разрешения пользователя.
8. Не считай функцию проверенной без тестирования.
9. Объясняй изменения на русском языке.
10. После каждого этапа обновляй документацию проекта.

В первую очередь сохраняй работоспособность камеры,
выбора деталей и уже исправленного соединения ATX24.
